# Project Title
ESP32 Expansion board 

## Project Discription

The ESP32 Expansion Board is a custom-designed auxiliary board built to extend the functionality, accessibility, and usability of the ESP32 microcontroller module. It breaks out all available GPIO pins into standard, easy-to-use headers, adds essential on-board circuits, and integrates common interfaces—making it suitable for prototyping, education, and embedded system projects. The board is designed to simplify wiring, reduce loose connections, and support rapid development for applications such as IoT devices, sensor networks, robotics, and automation systems.
---

## Features
- Full GPIO Breakout: All ESP32 pins (digital, analog, communication, power) are routed to 2.54mm pitch headers for easy connection.
​
- Power Management: On-board 5V to 3.3V voltage regulator, reverse polarity protection, and LED power indicator; supports power supply via USB, external adapter, or battery.
​
- Integrated Interfaces: Built-in I2C, SPI, UART, and PWM headers; dedicated ports for I2C sensors, SD card modules, and LCD displays.
​
- User Input & Output: Includes 2 pushbuttons (for reset and user-defined functions) and 3 indicator LEDs (power, status, activity).
​
- Compatibility: Fits standard ESP32-WROOM-32 and ESP32-WROVER modules; works with breadboards or direct wiring.
​
- Location-Suitable Design: Robust layout ideal for projects developed and tested in Iraan, Rizal—usable for local school projects, community automation, or IoT solutions tailored to the area’s needs.
​
- Compact & Durable: Optimized board size, clearly labeled pins, and stable traces to prevent errors during assembly and use.

## Components

- ESP32 Devkit V1
- Voltage Regulator (AMS1117-3.3V)
​
- Schottky Diode (1N5819) – reverse polarity protection
​
- Electrolytic Capacitors (10μF, 47μF)
​
- Ceramic Capacitors (0.1μF, 1μF)
​
- Power LED (Red) + Current Limiting Resistor (220Ω)
​
- 2-pin Power Input Header (5–12V)
​
- Micro-USB Port (for power and data)
 
I/O & Connection
 
- 2.54mm Female Headers – for all GPIO pins
​
- Dedicated I2C Header (SDA, SCL, VCC, GND)
​
- Dedicated SPI Header (SCK, MOSI, MISO, CS, VCC, GND)
​
- UART Header (TX, RX, VCC, GND)
​
- SD Card Module Slot / Header
​
- LCD 16x02 / 20x04 Header
 
Input / Output Elements
 
- Pushbuttons – 2 units (RESET and USER)
​
- LEDs – 3 units (Power, Status, Activity)
​
- Resistors (220Ω – for LEDs; 10kΩ – for pull-up/pull-down on buttons)
